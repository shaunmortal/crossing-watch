Run it on your own crossing

Python 3.11+ and ffmpeg. The self-checks and the synthetic sample need no key; your own video needs a Meta Model API key.

git clone https://github.com/shaunmortal/crossing-watch && cd crossing-watch
python3 test_cw.py                          # self-checks, under a minute
python3 pack.py sample sample/site.json     # the synthetic sample, no key
python3 monday.py your-video.mp4 sites/your-site.json --budget 14 --yes   # your crossing

This page replays recorded results; it calls no model. Rules: serious under the threshold you set, close pass under 3.0 s; a track Muse Spark calls a rider or not a person is removed from every event, as pack.confirmed does.
